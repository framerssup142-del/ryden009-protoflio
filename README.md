# موقع رياض إبراهيم (رايدن)

بورتفوليو Video Editor بفكرة "جلسة مونتاج":
- الصورة الرئيسية في **شاشة عرض**، بتظهر الأول "خام" وبعدين بتتلوّن زي الـ Color Grading.
- **تايم لاين** تحت الصورة: كل قسم في الصفحة كليب، والـ playhead بيمشي مع السكرول، ولما تنزل بيثبت فوق كشريط تنقّل.
- **الشغل متقسّم حسب المجال** (فيتنس، طبي، عقارات، موشن...) بفلاتر، وكل فيديو بيشتغل في مشغّل جوه الموقع.
- أقسام: الشغل، النتايج (أرقام + سكرين شوتات)، عني، الخدمات وطريقة الشغل، تواصل.
- كل المحتوى بيتعدّل من **لوحة التحكم** من غير ما تلمس الكود.

---

## 1) Firebase
الموقع مربوط بالفعل بمشروعك `ryden-potoflio` (البيانات في `js/firebase-config.js`).
لو هتعمل مشروع جديد:
1. Firestore Database → Create database
2. Authentication → Sign-in method → فعّل Email/Password
3. Authentication → Users → ضيف يوزر بإيميلك وباسورد (ده حساب الأدمن)

## 2) قواعد الأمان (Firestore → Rules)
نفس القواعد القديمة، مفيش حاجة اتغيرت:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /videos/{videoId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /site/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /impact/{shotId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

## 3) الرفع على GitHub Pages
ارفع كل الملفات دي مكان القديمة في نفس الـ repo (على `main`)، والـ workflow اللي في `.github/workflows/static.yml` هيرفع الموقع لوحده.

بعد ما الموقع يشتغل، افتح `index.html` وغيّر سطر `og:image` للينك الكامل لصورتك
(مثلًا `https://USERNAME.github.io/REPO/assets/images/profile.jpg`) عشان صورتك تظهر لما حد يبعت لينك الموقع على واتساب.

## لوحة التحكم
ادخل على `yourdomain/admin.html`، أو وانت في الصفحة الرئيسية اكتب كلمة **`ryden`** من الكيبورد.
(تقدر تغيّر الكلمة دي في `js/site.js`، دوّر على `const SECRET = "ryden"`.)

### تاب «المحتوى»
- **صورتك**: ارفعها من هنا وهتتصغّر تلقائي. أحسن حاجة صورة طولية (4:5) وانت في نص الكادر.
  أو بدّل الملف `assets/images/profile.jpg` بصورتك بنفس الاسم.
- **الجملة الكبيرة**: أول حاجة الزائر بيقراها. خليها قصيرة (2 لـ 4 كلمات).
- **النبذة**: كل فقرة في سطر لوحدها. أول فقرة بتظهر أوضح من الباقي.
- **الخبرة / البرامج**: لو سبتهم فاضيين مش هيظهروا.
- **الخدمات**: كل خدمة في سطر بالشكل ده: `العنوان | الوصف`
- **Showreel** (اختياري): لو حطيت لينك، هيظهر فيديو كبير فوق الشغل.

### تاب «الشغل»
- **ضيف فيديو**: لينك يوتيوب أو تيك توك أو انستجرام أو جوجل درايف. الفيديو الجديد بيظهر أول واحد.
- **اسم العميل والمجال**: دول اللي بيظهروا على كارت الفيديو، والمجال هو اللي بيعمل الفلاتر.
  الفيديوهات القديمة الموقع بيستنتج اسم العميل والمجال من العنوان (مكتوب جنبهم «تلقائي»)، واكتب فوقهم لو عايز تغيّرهم.
- **الترتيب**: بالأسهم ↑ ↓. الترتيب هنا هو نفس ترتيب الموقع.
- **صورة الغلاف** (اختياري): الموقع بيجيب صورة الفيديو من يوتيوب ودرايف لوحده.
  لو الصورة مش حلوة أو الفيديو من تيك توك/انستجرام، ارفع غلاف بنفسك.
  **مهم:** فيديوهات جوجل درايف لازم تكون متشاركة "Anyone with the link" عشان تشتغل وصورتها تظهر.

### تاب «النتايج»
- **الأرقام**: حط أرقامك الحقيقية (المشاهدات، العملاء، سنين الخبرة...).
  لو سبتها فاضية، الموقع بيعرض +1M مشاهدات وعدد العملاء والمجالات من الفيديوهات لوحده.
- **سكرين شوتات**: صور لنتايج حقيقية (مشاهدات، تفاعل) ومعاها وصف ولينك الفيديو لو حابب.

## الملفات
| الملف | فيه إيه |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `admin.html` | لوحة التحكم |
| `css/style.css` | تصميم الموقع (الألوان والخطوط في أول الملف) |
| `css/admin.css` | تصميم لوحة التحكم |
| `js/site.js` | تحميل المحتوى، الفلاتر، المشغّل، التايم لاين |
| `js/admin.js` | كل وظايف لوحة التحكم |
| `js/utils.js` | المحتوى الافتراضي، قراءة اللينكات، ألوان المجالات |
| `js/firebase-config.js` | بيانات مشروع Firebase |

لون كل مجال متحدد في `js/utils.js` (`CATEGORY_COLORS`). أي مجال جديد بياخد لون لوحده.
